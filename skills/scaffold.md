PROJECT SCAFFOLD RULES:
- Use the scaffold tool for any project requiring 2 or more files.
- Always include a requirements.txt or package.json in the scaffold files list.
- Always include a README.md with setup instructions.
- stack parameter must be one of: python, flask, fastapi, react, node, html, game.
- project_name must be lowercase, no spaces (use underscores).
- After scaffolding, verify the manifest exists at projects/<name>/.mayday_manifest.json.
